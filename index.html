🎯 What Is Doomium?

Doomium is a plugin for Altium Designer 25, the popular software used to design printed circuit boards (PCBs). It adds a small playable window inside the application so you can launch and play the original DOOM while your design tools stay open in the background.

You do not need to know anything about programming, code, or electronics to use Doomium. If you can install a normal Windows program and open a menu inside Altium Designer, you can use this plugin. Everything is done with a few clicks.

The project is built with C# and the .NET framework, which means it runs as a normal Windows application alongside your existing Altium Designer installation. It does not change your PCB files, your design rules, or your project settings. It simply adds a small extra panel where the game can be played.

Good to know: Doomium is a fun side project made for people who already use Altium Designer. It is not a replacement for the software and it is not required for any design work.

🖥️ System Requirements

Doomium is designed to run on ordinary Windows machines alongside Altium Designer. To keep things smooth, your computer should meet the following baseline:

  • Operating system: Windows 10 or Windows 11, 64-bit.
  • Altium Designer: Version 25 installed and activated on the same computer.
  • Software framework: .NET Framework 4.8 or newer (most Windows 10 and Windows 11 PCs already have this installed).
  • Memory: 8 GB of RAM or more, in line with the usual recommendations for Altium Designer.
  • Graphics: A graphics card or integrated graphics chip that supports standard Windows display acceleration.
  • Storage: A small amount of free disk space, around 100 MB, for the plugin files.
  • Input: A keyboard and mouse. A numeric keypad is helpful but not required.

If Altium Designer 25 runs comfortably on your computer today, Doomium will run comfortably too. The game panel uses only a small share of your system's resources.

🎮 Playing DOOM Inside Altium Designer

Once the plugin is installed and Altium Designer has restarted, playing is straightforward:

  1. Open Altium Designer 25 as you normally would.
  2. Locate the Doomium panel or menu entry inside the application. It is usually grouped with the other add-on panels.
  3. Click it to open the game window. The first launch may take a few seconds while the game prepares itself.
  4. Click inside the game window so it receives your keyboard input.
  5. Use the standard DOOM movement keys to walk, turn, and interact, and press the fire key to shoot. The controls are listed inside the panel.
  6. To return to your design work, click outside the game window or close the panel. Your Altium Designer workspace is unaffected.

A few practical tips

  • Save your PCB work before you start playing, so a distraction never costs you progress.
  • If your keyboard shortcuts stop responding in Altium Designer while the game is focused, click back into the main application window to regain control.
  • Use a windowed layout if you want to keep an eye on your design while you play.
  • Turn the in-game sound down if you share an office or are on a call.

🔧 Troubleshooting

The Doomium panel does not appear

Close Altium Designer completely, including any background processes, and start it again. Plugins are only loaded when the application starts up. If the panel still does not show, re-run the file you downloaded and install it once more.

Windows blocks the file from running

Windows sometimes warns about files downloaded from the internet. When the warning appears, choose the option that keeps and allows the file, then run it again. If your organisation manages your computer, you may need to ask your IT department for permission.

The game window opens but the keyboard does not respond

Click once directly inside the game window to give it focus. Altium Designer keeps its own keyboard shortcuts, and the game only receives your key presses when its window is active.

The game runs slowly

Close other heavy applications and background windows. Large PCB projects with many layers can use significant memory, so give the game a little breathing room by closing projects you are not currently working on.

I want to remove Doomium

Uninstall it the same way you installed it, using the uninstall option that came with the downloaded file, or remove it from the Windows list of installed programs. Altium Designer will simply stop showing the panel on its next start.
